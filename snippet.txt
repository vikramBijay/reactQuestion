### Step 2 — Rendering Function Mein Markdown Code Blocks Ko HTML Mein Convert Karo

> [!IMPORTANT]
> `index.html` ke andar jahan answer render hota hai (innerHTML set hota hai), wahan ek helper function add karna hai jo ` ```python ... ``` ` ko `<pre><code class="language-python">...</code></pre>` mein convert kare.

**Naya function add karo** (JS section mein, render function se PEHLE):

```javascript
function formatAnswer(text) {
    // Step A: Code blocks convert karo (```language ... ```)
    text = text.replace(/```(\w+)?\n?([\s\S]*?)```/g, function(match, lang, code) {
        lang = lang || 'text';
        // HTML special characters escape karo
        code = code.trim()
            .replace(/&/g, '&amp;')
            .replace(/</g, '&lt;')
            .replace(/>/g, '&gt;');
        return '<pre><code class="language-' + lang + '">' + code + '</code></pre>';
    });
    
    // Step B: Inline code convert karo (`code`)
    text = text.replace(/`([^`]+)`/g, '<code class="inline-code">$1</code>');
    
    // Step C: Bold text convert karo (**text**)
    text = text.replace(/\*\*([^*]+)\*\*/g, '<strong>$1</strong>');
    
    // Step D: Blockquote convert karo (> text)
    text = text.replace(/^>\s*(.+)$/gm, '<blockquote>$1</blockquote>');
    
    // Step E: Newlines ko <br> mein convert karo (but pre ke andar nahi)
    // Pehle pre blocks protect karo, phir newlines replace karo
    
    return text;
}
```

Aage se answers likhte time bas in 4 rules ka dhyan rakhna:

1. Multi-line Code Block ke liye (Bada code): Apne code ko start karne se pehle 3 backticks ( ` ) aur language ka naam likho (jaise python yajavascript), phir apna code likho, aur end mein wapas 3 backticks laga do. Yahi trick hai jisse system usko colourful box mein daal dega.

2. Inline Code ke liye (Chota text ya function ka naam): Agar tumhe kisi line ke beech mein bas ek chota sa function ya variable highlight karna hai, toh us word ke aage aur peeche sirf ek single backtick ( ) laga do (jaiseprint()` likhna). Wo automatically ek grey background wale chote tag mein aa jayega.

3. Highlighted Quote (Blockquote) ke liye: Agar koi definition ya summary alag se highlight karke dikhani hai, toh us line ke shuru mein > (greater-than sign) aur ek space de do. Wo automatically ek sundar italic text ban jayega jiske left mein ek amber color ki line hogi.

4. Bold Text ke liye: Kissi bhi word ya line ko bold karne ke liye uske aage aur peeche do taare ( ** ) laga do. Jaise yeh bold hai.

## 📋 New Topic File Add Karne Ka Plan

### Step 1 — Data File banao / format karo
Naye `.js` file ki **pehli line** mein variable declare karo:
```
const CSS_DATA = [ ... ]
```
Aur **last line** pe semicolon lagao:
```
];
```
Har object mein `"topic": "css"` field hona chahiye (jo tumhare topic name se match kare).

---

### Step 2 — `index.html` mein 3 jagah change karo

**2a. Script tag add karo** (baaki script tags ke paas):
```
<script src="cssQuestions.js"></script>
```

**2b. DATA array mein spread karo** (same line pe):
```
const DATA = [...REACT_DATA, ...PYTHON_DATA, ...JAVASCRIPT_DATA, ...CSS_DATA];
```

**2c. Sidebar Dropdown mein option add karo:**
```
<div class="mac-dropdown-item" data-value="css">CSS</div>
```

**2d. Hexagon Home Page mein `data-topic` match karo:**
Hexagon pe `data-topic="css"` — ye value exactly wahi honi chahiye jo data file mein `"topic": "css"` likha ho.

---

### ⚠️ Ek Important Rule

`data-topic` (hexagon HTML) = `data-value` (dropdown HTML) = `topic` field (JS data file) — **teeno ekdum same spelling** hone chahiye, warna filter kaam nahi karega. Ye hi bug tha JS wali file mein (`"js"` vs `"javascript"`).
